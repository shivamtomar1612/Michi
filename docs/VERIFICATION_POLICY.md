# Verification policy

## Host identity

An account is not proof of operator identity or authorization. A host application must establish identity, organization, official website/contact, authorization evidence, operating details, cultural rules, accessibility disclosures, availability, capacity, and cancellation terms. An administrator must check ownership/authorization before selecting `verified`; the existing RPC rejects verification unless the ownership check is acknowledged. The status does not imply government, venue, or tourism-board endorsement.

The existing statuses are `draft`, `submitted`, `under_review`, `verified`, `rejected`, and `suspended`. Only verified, eligible hosts can publish MICHI-bookable experiences. Suspension pauses the host's active experiences while preserving confirmed booking records.

## Experience verification

An external verified discovery listing remains separate from a MICHI-participating host experience. An external listing does not create MICHI availability or booking capacity. The existing experience approval RPC requires a verified host application and adequate cultural context/meeting details before publication. The administrator must review ownership, factual description, cultural claims, accessibility, pricing, slot capacity, photography, safety, and source information before approval.

## Cultural evidence

The Phase 6 knowledge manager remains authoritative for source registration, access-terms review, exact URL approval, extraction preview, provenance, conflict review, verification, freshness, and disabling content. Hosts may provide community-verified rules; they cannot assign official source status. Conflicts and stale records remain visible for human review.

## Destination publication

The admin editor changes destination name, description, cultural summary, and publication state only. It preserves source URL, source ID, authority, verification state, coordinates and signal values. Publication is rejected if the current destination lacks verified-official status, a source record, source URL, or last-verified timestamp. Crowd pressure and health signals are not manually editable through this page.
